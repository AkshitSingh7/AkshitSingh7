### 🛰️ Experience Highlight: ISRO (RRSC-West)
My core expertise lies in **Geospatial Deep Learning**, honed during my tenure as a Research Intern at the **Indian Space Research Organisation (RRSC-West)**.

I was tasked with automating the mapping of sand dunes using high-resolution multi-spectral satellite imagery—a critical task for monitoring desertification. This was not a standard computer vision problem; it required handling massive raster datasets, correcting for atmospheric noise, and managing the unique spectral signatures of geological features.

* **The Tech:** I engineered a custom pipeline using **GDAL** and **Rasterio** for geospatial data preprocessing.
* **The Models:** I conducted a rigorous comparative analysis, benchmarking **U-Net** architectures against **Transformers** to optimize segmentation accuracy.
* **The Impact:** The resulting system provided a scalable method for automated landform classification, significantly reducing the manual effort required for geological mapping.
* *Note: Due to the sensitive nature of satellite data and government protocols, the source code for this project remains proprietary and cannot be published.*
